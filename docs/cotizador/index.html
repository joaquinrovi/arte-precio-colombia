Cómo funciona

El modelo utiliza remates históricos de Bogotá y las características que indicas. Las estimaciones son orientativas.

Si el artista es nuevo

El modelo estima con las características de la obra. Guardar un nombre en este navegador te permite reutilizarlo. Para que el modelo aprenda de las ventas de ese artista, hace falta incorporar sus registros y volver a entrenarlo.

Precisión observada

En 179 lotes de 2026, el error porcentual absoluto mediano fue del 54 %. Entre los 31 lotes de artistas nuevos para el modelo, fue del 85 %.
